# Failure modes

## Wrong denominator
The arithmetic is valid but answers a different question. Response: denominator is explicit in the API.

## Modelled value is presented as measured
An assumption is multiplied by a real count and loses its label. Response: basis travels with the figure.

## Missing attribution join
The system cannot prove which later outcome came from which earlier event. Response: return unavailable.

## Zero denominator
A rate would divide by an empty population. Response: return unavailable instead of a misleading zero.

## Metric label is detached
A number is copied without its basis/context. Response: quote only measured figures whose object still carries the label.

## Dashboard pressure
A stakeholder wants “some number” even when the data is weak. Response: keep the limitation visible rather than estimating around it.
