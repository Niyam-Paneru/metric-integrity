# Invariants

1. **Every rate has a named denominator.**
2. **Every figure carries its basis.**
3. **Modelled does not become measured through arithmetic or formatting.**
4. **Unsupported attribution produces no numeric claim.**
5. **Zero-denominator rates are unavailable, not zero.**
6. **Only measured figures are safe to quote as measured results.**

If the data cannot support the sentence, the number does not get to rescue it.
